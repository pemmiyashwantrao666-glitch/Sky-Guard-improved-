HOW IT WORKS

Detection Workflow

Four stages from raw sensor data to actionable alert — fully automated, running continuously across all stations.

01

📡 Ingest

Weather stations stream readings every second into the ingestion pipeline.

➜
02

🧹 Clean

Readings are validated, de-noised and normalized against station baselines.

➜
03

🧠 Detect

The anomaly engine scores each reading using z-scores and rolling statistics.

➜
04

🚨 Alert

Anomalies are ranked by severity and pushed to the map, feed and alerts.
